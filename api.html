Gastronavt API

API платформы Gastronavt предназначен для интеграции товароучетных систем, сторонних приложений, CRM и прочих учетных систем с Gastronavt.

Базовый endpoint:
https://АДРЕС_АПИ/index.php?entryPoint=GastronavtApi

Реальный адрес API выдается индивидуально и может быть получен через поддержку в Telegram.

✈️ Написать в Telegram

Авторизация

Все запросы выполняются с использованием параметра secret_key, который выдается разработчиком Gastronavt для каждой площадки (landing).

Получить secret_key и реальный адрес API можно через поддержку в Telegram:

Обновление заказа

POST

Метод позволяет обновить данные существующего заказа. Для идентификации заказа необходимо передать order_id или order_name.

Поддерживается частичное обновление — можно передавать только те поля, которые требуется изменить.

Параметры

Параметр Обязательный Описание
method Да Имя метода API — updateOrder
secret_key Да Секретный ключ площадки
order_id Нет* Внутренний идентификатор заказа
order_name Нет* Номер заказа (отображаемый)
* Необходимо передать order_id или order_name

Обновляемые поля

Поле Описание Формат
status Статус заказа (через маппинг Gastronavt) Строка / код статуса
pay_method Способ оплаты Код способа оплаты
comment Комментарий к заказу (до 255 символов) Строка
receiving_method Способ получения заказа Код способа получения
delivery_date Дата доставки dd.mm.yyyy
delivery_time Время доставки HH:MM

Все значения status, pay_method, receiving_method проходят проверку и маппинг на стороне платформы Gastronavt. При передаче неподдерживаемого значения метод вернет ошибку.

Пример запроса

{
  "secret_key": "G3mW2yS7pHq9xN1aC4v7kQ2zT8l5bR0fE6c3dU9mY1o",
  "method": "updateOrder",
  "order_name": "3360444",
  "status": "02"
}

Пример обновления даты и времени доставки

{
  "secret_key": "XXXX",
  "method": "updateOrder",
  "order_id": "e60c9052-3c49-7d9e-50e8-69595aa977ae",
  "delivery_date": "05.01.2026",
  "delivery_time": "14:30"
}

Пример обновления комментария и способа оплаты

{
  "secret_key": "XXXX",
  "method": "updateOrder",
  "order_name": "3360444",
  "comment": "Клиент попросил перезвонить",
  "pay_method": "02"
}

Пример ответа

{
    "message": "Order updated successfully",
    "order_id": "e60c9052-3c49-7d9e-50e8-69595aa977ae",
    "order_name": "3360444",
    "updated_fields": {
        "status_c": "02"
    }
}

Получение заказов

GET

Метод возвращает список заказов по указанным идентификаторам или номерам заказов. Можно передавать один или несколько order_id или order_name, разделяя значения запятой.

Параметры

Параметр Обязательный Описание
method Да Имя метода API — getOrders
secret_key Да Секретный ключ площадки (выдается Gastronavt)
order_id Нет* Внутренний идентификатор заказа. Можно передавать несколько через запятую
order_name Нет* Номер заказа (отображаемый). Можно передавать несколько через запятую
* Необходимо передать order_id или order_name

Примеры запроса

Получение одного заказа по id

{
  "method": "getOrders",
  "secret_key": "XXXX",
  "order_id": "e6b3fa67-6bf8-6492-0d80-695dfbf2b4ee"
}

Получение нескольких заказов по id

{
  "method": "getOrders",
  "secret_key": "XXXX",
  "order_id": "e6b3fa67-6bf8-6492-0d80-695dfbf2b4ee, a123b456-c789-0def-1234-567890abcdef"
}

Получение одного заказа по имени

{
  "method": "getOrders",
  "secret_key": "XXXX",
  "order_name": "3567978"
}

Получение нескольких заказов по имени

{

status Да Код статуса заказа

Пример запроса

method=getOrdersByStatus
secret_key=XXXX
status=20

Товары

GET

Метод возвращает список товаров. Поддерживается фильтрация по артикулу (vendor_code), внутреннему идентификатору товара (id) и признаку активности (active).

Все параметры являются опциональными. Если параметры не переданы, метод вернет все существующие товары, включая неактивные (выключенные).

Параметры

Параметр Описание
vendor_code Артикул товара. Можно передавать одно или несколько значений, разделенных запятой
id Внутренний идентификатор товара в системе Gastronavt. Поддерживается передача нескольких id через запятую
active Фильтр по активности товара: 1 — активные, 0 — неактивные

Примеры вызовов

Получение всех товаров

method=getProducts
secret_key=XXXX

Фильтрация по артикулу

method=getProducts
secret_key=XXXX
vendor_code=10000019012,10000039784

Фильтрация по внутренним id товаров

method=getProducts
secret_key=XXXX
id=11472d78-26ee-1305-5873-68c6999799b8,b0e93368-beee-7848-f9a6-69533769a8df

Получение только активных товаров

method=getProducts
secret_key=XXXX
active=1

Комбинированный пример

method=getProducts
secret_key=XXXX
vendor_code=10000029855
active=0

                "id": "51357f90-7efb-598c-1930-68c699930bd4",
                "name": "Полуфабрикаты"

        }

}
